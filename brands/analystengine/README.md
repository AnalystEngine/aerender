# AnalystEngine brand kit

AnalystEngine's design system as aerender libraries: tokens, screen components, marketing and document templates, and slide layouts. It is a worked example of a full brand kit. The `analystengine-brand` skill (`skills/analystengine-brand/`) tells agents how to use it.

| File | Alias | Contents |
|---|---|---|
| `tokens.css` | `aerender:analystengine` (for `lint --brand`) | The source design tokens |
| `tokens.lib.json` | `aerender:analystengine/tokens` | The tokens as variables, generated with `aerender tokens import tokens.css` |
| `ui.lib.json` | `aerender:analystengine/ui` | Screen and dashboard components, generated by `scripts/build-ui-lib.py` |
| `assets.lib.json` | `aerender:analystengine/assets` | Social card, LinkedIn square, A4 report cover, A4 one-pager, web hero; `scripts/build-assets-lib.py` |
| `slides.lib.json` | `aerender:analystengine/slides` | 1920x1080 slide layouts and a diagram kit; `scripts/build-slides-lib.py` |
| `assets/` | | Images used by the templates (see `CREDITS.txt`) |

## Rules agents must keep

- The near-black canvas (`ae-bg`, #181818) with surfaces stepping up through `ae-bg-section` and `ae-bg-elev`. Cards keep a 1px `ae-rule` border.
- One accent (`ae-accent`, #E6FC20) per visual, on the one thing that matters. Never use it as a large fill.
- One type family, Inter Tight. Eyebrows are capitals, bold, tracked 0.16em, in `ae-eyebrow`.
- Left-aligned grids and 60/40 splits. Content fills about 60% of a surface.
- Radii of 2px for controls and 4px for cards, 8px at most. Pills only for status chips and terminators.
- No gradients, patterns, decorative icons or emoji. Photography is monochrome.
- Plain, specific UK English: headlines of nine words or fewer, no em dashes, no hype.

## Rebuilding

Each generated library starts from an empty file and is rebuilt through the CLI:

```
python3 scripts/build-ui-lib.py > ops.json
echo '{"aerender":1,"imports":{"t":"tokens.lib.json"},"variables":{},"children":[]}' > brands/analystengine/ui.lib.json
aerender batch brands/analystengine/ui.lib.json ops.json
```

Component ids are fixed in the scripts, so scenes that use them keep working.
